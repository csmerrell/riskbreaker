## Astral Flow & Umbral Decay
All abilities are either [Astral] or [Umbral] aligned.
- Using an Astral ability pushes the user to [Umbral Decay].
- Using an Umbral ability pushes the user to [Astral Flow].
- Battle start: Enter the state of most-equipped abilities.

- [Astral Flow]
    - Astral skills gain bonus effects
    - +1% Party Regen

- [Umbral Decay]
    - Umbral skills gain bonus effects
    - +15% Party Dmg Reduction
    - [HiddenLinks]
        - 

## Skills
- (Basic) Astral Igni
    - Add a small, stacking potency dot to an enemy.
        - Ticks 10 times
        - Heals lowest %hp allied character each tick 
- (Basic) Umbral Rake
    - 80% CT cost.
    - Low potency 1-lane attack. Reduces enemies' atk potency 10% for 2 attacks.
- Umbral Shroud
    - Single target: Negate 1 received attack
    - On absorb:
        - Activate user's turn
        - Cooldown: 3
    - [Umbral]: Cooldown: 2
- Compress
    - Medium potency all enemy attack.
    - [Umbral]: All enemies* pull into single lane
        - *Max 3 enemies in space. Random selection.
